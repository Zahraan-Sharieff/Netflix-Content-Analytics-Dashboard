# 🎬 Netflix Content Analytics Dashboard

A Netflix-inspired analytics dashboard built using Python, Pandas, and Plotly to analyze Netflix movies and TV shows through interactive visualizations and KPI metrics.

---

# 📊 Features

- KPI Dashboard
- Content Distribution Analysis
- Top Countries Producing Netflix Content
- Netflix Content Growth Trends
- Interactive Plotly Visualizations
- Netflix-themed Dark UI

---

# 🛠 Technologies Used

- Python
- Pandas
- Plotly
- Google Colab
